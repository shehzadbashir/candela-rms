# Candela RMS - Retail Management System

A complete, production-ready Retail Management System with multi-store support, inventory management, POS, and comprehensive reporting.

## Features

- **Point of Sale (POS)** - Fast billing with barcode scanning and thermal receipt printing
- **Inventory Management** - Track stock, batches, expiry dates, and receive low stock alerts
- **Customer Management** - Profiles, loyalty points, and promotions
- **Multi-Store** - Centralized management with branch-level reporting
- **Reports & Analytics** - Sales reports, profit/loss, inventory valuation, export to Excel/PDF
- **Role-Based Access** - Admin, Manager, Cashier with specific permissions
- **FBR Compliant** - Digital invoicing with configurable tax rules
- **Bilingual** - English and Urdu language support

## Tech Stack

- **Frontend**: Next.js 14, React, TailwindCSS, Recharts
- **Backend**: Node.js, Express, Prisma ORM, PostgreSQL
- **Authentication**: JWT with bcrypt
- **Deployment**: Docker, Nginx reverse proxy
- **Hardware Integration**: Barcode scanners, ESC/POS thermal printers
